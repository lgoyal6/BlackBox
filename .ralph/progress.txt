PHASE-01 is the only prerequisite. The moment `npm run typecheck` passes in PHASE-01, all fourteen
remaining phases can be started simultaneously by different agents. Own only your phase's files
(see the ownership table in overview.md) and set the `*_MODE` env vars of the ports you consume to
`fake` so your phase verifies without waiting on anyone.

## Pre-Build Findings (already done — do not repeat this work)

**Date:** 2026-08-13
**By:** planning session

**Verified live against the Socrata API** (`76xm-jjuj`, no auth required):
- 29,978,154 total NYC EMS incidents on record
- 845,887 of 5,653,498 incidents since 2023 had the call type change after arrival = **15.0%**, the headline number
- 2,750,007 of 29,978,154 all time = 9.2%
- 400,548 undertriaged since 2023 (severity upgraded after arrival) = 7.1%
- 237,210 incidents reopened = 0.79%
- Top transitions since 2023 include `UNC`→`ARREST` (14,987) and `SICK`→`CARD` (15,966), which became the demo pair
- Severity code direction resolved empirically: mean response time rises monotonically from code 1 (309 s) to code 8 (2837 s), so lower code = more severe. Codes 0 and 9 are noise.
- JSON API keys are lowercase snake_case and the identifier is `incident_id`, not `CAD_INCIDENT_ID`
