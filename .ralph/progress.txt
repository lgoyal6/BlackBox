**Tasks:** US-019, US-020

**Files Modified:** None
**Ports Implemented:** EventsPort at `src/lib/events/index.ts`
**Fakes Used During Build:** EMBEDDINGS/RETRIEVAL/MEMORY/LLM/GRAPH/VOICE=fake, EVENTS_MODE=real
**Key Decisions:**
- `nextSeq` is a single `$inc` `findOneAndUpdate` on `_watch_state`, namespaced `seq:*`. Verified gap-free and duplicate-free under 200 concurrent emits.
- SSE route opens the change stream before the replay `find()` and dedupes by `_id`, so nothing is lost in the snapshot/subscribe window.
- Replay boundary is SSE comments (`: replay <n>` / `: live`), not a synthetic event kind, because the §8 union is closed.
- `watchEvents` waits 250 ms for an immediate stream error so a non-replica-set target rejects rather than hanging; the route then degrades to `SSE POLL FALLBACK`.
**Issues Found & Fixed:**
- `import { recent } from "@/lib/events"` does not compile: that specifier is the ambient declaration in `real-ports.d.ts`, which exports only the default. Import `@/lib/events/index` for named exports. Logged in `agents.md`.
**Contract Changes:** None
**Verification Results:**
- typecheck clean, `npm run build` succeeds.
- 200 concurrent emits -> 200 rows, 200 unique seq, min 1 max 200; all `_id` are strings.
- `emit` resolves and logs `EVENT EMIT FAILED` with an unreachable `MONGODB_URI`, exit 0.
- 40 fixture events replayed as `: replay 40` + 40 `data:` frames, all parsing to a §8 `kind`; `: live` marker; `: ping` within 15 s; a cross-process `tsx` insert appeared as frame 41 within 2 s.
- All four response headers exact. `?incidentId=` (empty) returns 200 and warns.
- 5 connect/disconnect cycles -> last `[events] change stream closed (open=0)`.
**Next:** PHASE-14 renders these frames; PHASE-11 and PHASE-12 can call `emit` on latency-budgeted paths.
